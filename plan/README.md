# 分析計畫總覽

最後更新:2026-11-27

這裡放所有分析計畫和審查紀錄。流程規則寫在根目錄 `AGENTS.md`,簡單說就是:

```
提出問題 → AI 寫計畫 v1 → 獨立 AI 第一次審查 → 修改成 v2
        → 獨立 AI 第二次審查 → 通過 → Pull Request 由另一位組員 Approve
        → 合併並打 tag(例如 IN02-v2-locked)→ 鎖定 → 才能寫程式
```

鎖定後的計畫不可修改。要改就寫新版本，並在「偏離紀錄」說明原因，以及當時是否已看過結果。Git 歷史和 tag 可以證明鎖定後沒有被修改。

組員一律用 GitHub 帳號稱呼(公開 repo,不寫真名)。

## 小組疑慮與對應計畫(11/20 對話紀錄)

| 疑慮或想法 | 對應計畫 |

| 沒有常態就取對數 | 所有分析一律用 log 單價(PRE02) |
| 高中低樓層分三組；總樓層不同，低中高不能直接比 | PRE01 定義相對位置;IN04 S2 |
| 2 樓可能比較便宜(水管等) | IN03 放 2 樓虛擬變數並做次要檢定 |

| 只研究 3、4、5 樓 | IN02 |
| 5 樓是頂樓，可能比較便宜 | PRE01 定義頂樓;IN02 用 E7 組避開;IN04 S3 分開頂樓和 4 樓 |
| 選總樓層 6、7 樓以上 | IN02 的 E7 組(總樓層 ≥ 7) |
| 20 樓大樓的 3–5 樓是相對低樓層 | IN04 S1 依總樓層分組 |

## 全專案已知資訊揭露

寫計畫之前，我們已經看過以下結果。審查時要確認計畫沒有利用這些結果挑選有利的設定。

- **2026-11-18 預試**:臺北市 115 年第 2 季，公寓、華廈、住宅大樓，排除親友與特殊交易後 3,025 筆。已看到的結果:
  - 4 樓平均每坪單價低於其他樓層(t 檢定顯著)。4 樓物件的平均屋齡較高、有電梯的比例較低。
  - 雙因子 ANOVA(3/4/5 樓 × 有無電梯):樓層主效果不顯著，電梯主效果和交互作用顯著。Tukey 比較中,4 樓和 3、5 樓沒有顯著差異。
  - 複迴歸沒有放樓層×電梯交互作用時,4 樓約 −4.5%(顯著)；加入交互作用並用 HC3 標準誤後,4 樓效果接近 0、不顯著。
  - 迴歸殘差不等變異(Breusch–Pagan 顯著)、非常態；各行政區變異數不同(Levene 顯著)。
  - 估價誤差(MAPE):Random Forest 約 12%,迴歸約 17%。
- **2026-11-20 資料下載與計畫撰寫**:看過 12 季資料的筆數、欄位格式、樓層 × 建物分組 × 有無電梯的筆數(細節見 PRE01 第 2 節)。沒有計算任何價格相關的統計量。
- **2026-11-27 第一次審查與 v2 撰寫**:審查者與撰寫者看過 `移轉層次`、門牌、備註的格式與筆數，以及不同切分比例下的筆數與建物數(細節見 PRE01 v2、PRE02 v2 第 2 節)。沒有讀取任何價格欄位。
- **2026-11-27 PRE01 第二次審查**:審查者看過 I5 白名單各附屬空間在 1 樓 / 中間樓層 / 頂樓的筆數，以及 x1 關鍵字比對到的備註片段(見 PRE01 `v2_審查.md` S1、S2、S9)。只有筆數，沒有讀取任何價格欄位。

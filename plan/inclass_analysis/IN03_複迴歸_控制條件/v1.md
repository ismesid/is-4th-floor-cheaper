## 0. 要討論的問題

把屋齡、地段、電梯、樓層趨勢、頂樓等條件都放在一起，4 樓還剩多少效果?每個推測(屋齡說、地段說、電梯說)各解釋了多少?

## 1. 目的與研究問題

- Q3:其他條件相同時,4 樓的每坪單價是否和其他樓層不同?差多少 %?
- Q3b:逐步加入控制變數時,4 樓係數怎麼變化?

## 2. 事前已知資訊揭露

預試中，沒放樓層×電梯交互作用時 4 樓約 −4.5%(顯著)；放了之後接近 0。預試的殘差不等變異、非常態。本計畫一律使用叢集穩健標準誤，不依預試結果切換方法。

## 3. 資料

- 確認樣本，PRE01 清理後的全部樓層(1 樓到最高樓層)。

## 4. 變數定義

沿用 PRE01。另定義:
- `floor_c` = floor − 5(置中，減少共線性)。

## 5. 推測與預期

| 推測 | 如果成立，預期會看到 |
|---|---|
| 屋齡說 | M1 → M2,4 樓係數往 0 靠近 |
| 地段說 | M2 → M3,4 樓係數往 0 靠近 |
| 電梯說 | M3 → M4,4 樓係數往 0 靠近 |
| 忌諱說 | M5 的 4 樓係數仍顯著為負，且超過 −2% |

## 6. 分析方法

**階層式迴歸**(依事先決定的順序加入變數，不是 stepwise 自動選模):

| 模型 | 式子(被解釋變數皆為 log_price) |
|---|---|
| M1 | f4 |
| M2 | M1 + age + age² |
| M3 | M2 + C(district) |
| M4 | M3 + elevator + floor_c + floor_c² + elevator:floor_c + elevator:floor_c² + top + f1 + f2 + C(btype) |
| M5 | M4 + ln(area_ping) + rooms + has_mgmt + has_ext + has_park + C(quarter) |

- 所有模型使用同一份樣本(M5 變數無缺漏的列)。
- 標準誤：以 building_id 為叢集的穩健標準誤。
- **為什麼放 f1、f2、top**:1 樓常有店面或庭院溢價；小組提出 2 樓可能因水管等問題較便宜；頂樓可能因漏水、曝曬較便宜。不放的話，這些效果會被樓層趨勢吸收，扭曲 4 樓係數。

**迴歸診斷**(M5)

| 檢查 | 方法 | 事先決定的處理 |
|---|---|---|
| 共線性 | VIF(連續變數與二元變數，不含行政區、季別虛擬變數) | VIF > 10 的變數在報告中標註；不刪變數 |
| 等變異 | 殘差對配適值圖、Breusch–Pagan | 已使用叢集穩健標準誤，不另外處理 |
| 常態 | 殘差 QQ plot | 樣本大，不另外處理，報告中說明 |
| 影響點 | Cook's D > 4/n | 計算筆數；刪除後重跑 M5 列入 IN04 敏感度分析 |
| 模型比較 | AIC(M1–M5)、M3 vs M4 的 F 檢定(古典版) | 只做呈現 |

## 7. 決策規則

- **主要假設 H-P2**:M5 的 f4 係數 ≠ 0。和 IN02 的 H-P1 做 Holm 校正，α = 0.05 雙尾；判讀依 PRE02 的 TOST 規則(±2%)。
- **次要分析**:M1–M4 的 f4 係數只做描述(係數變化圖)，不另做檢定結論。M5 中 f2 的係數(小組提出的 2 樓疑慮)作為次要檢定，單獨一族。
- 主要假設 H-P1 和 H-P2 結論不一致時，兩個都報告，並說明差異可能的原因(IN02 只比較 E7、W5 兩組,IN03 是全部樓層並控制條件)。
